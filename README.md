# 📝 Aplicación de Notas

Aplicación web desarrollada con React que permite crear y administrar notas de manera sencilla. Este proyecto tiene como objetivo practicar el manejo del estado con los hooks de React y la persistencia de datos en el navegador.

## ✨ Funcionalidades

- Crear notas: agregar notas con título y descripción.
- Leer notas: visualizar las notas guardadas.
- Editar notas: modificar el título y la descripción de una nota existente.
- Eliminar notas: borrar notas que ya no necesitas.
- Favoritos: marcar y desmarcar notas como favoritas.
- Validaciones: verificar la longitud del título y la descripción.
- Persistencia de datos: guardar las notas en localStorage para conservarlas al recargar la página.
- Filtrar las notas favoritas.

## 🛠️ Tecnologías utilizadas

React — biblioteca para construir interfaces de usuario.
JavaScript (ES6+).
Tailwind CSS — estilos y diseño de la interfaz.
React Hooks:
useState para manejar formularios, validaciones y modales.
useReducer para centralizar las acciones de las notas.
useEffect para sincronizar las notas con localStorage.
Lucide React — iconos de la interfaz.
Vite — herramienta de desarrollo y compilación.

## 📦 Instalación

Clona el repositorio:

git clone URL_DE_TU_REPOSITORIO

Entra en la carpeta del proyecto:

cd nombre-del-proyecto

Instala las dependencias:

npm install

Inicia el servidor de desarrollo:

npm run dev

Abre en el navegador la URL que muestra la terminal.

## 🧠 Aprendizajes

Con este proyecto practiqué:

- La creación de componentes reutilizables en React.
- La creación de hooks personalizados.
- El manejo del estado con useState y useReducer.
- La separación de la lógica de negocio de la interfaz.
- El uso de acciones y dispatch para actualizar el estado.
- La persistencia de información con localStorage.
- La validación de formularios y la actualización de listas.
- Filtrar las notas favoritas.
